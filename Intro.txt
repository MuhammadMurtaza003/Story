API = Application Programming Interface 
    = Set of rules and protocol that define how one software interact with differnet software 
    = It bridges the communication between the differnet pieces of software
    = An API allows one application to request and receive data from another application.
    = In APIs We are making the GET request to get data.
    = In response, How is data coming back is structured.

Private APIs = For your use only means to communicate with server
Public APIs =  for public use 


Example = 

A website needs to display the current weather on its loading page. There is a specific weather service website that continuously updates and stores weather information.
To retrieve weather data from that website, we need an **API (Application Programming Interface)**, which acts as an interface between our website and the weather service,
allowing them to communicate and exchange data.
